# Video Game Catalog Ontology (VGCO)

## Overview

VGCO is an OWL ontology and knowledge graph for modeling video games and their metadata.

## Features

* OWL ontology modeling of games, genres, platforms, developers, and publishers
* SPARQL querying support
* SHACL validation rules
* Planned LLM-powered natural language to SPARQL interface

## Technologies

* Protégé
* OWL / RDF / Turtle
* GraphDB / RDFlib
* SPARQL
* SHACL
* Python

## Repository Structure

* ontology/: ontology source files
* queries/: SPARQL competency queries
* validation/: SHACL constraints
* examples/: sample RDF data
